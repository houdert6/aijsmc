# AI JS Minecraft
![Version 1.9.2.1](https://img.shields.io/badge/Version-1.9.2.1-3C8527)

This is the official GitHub Repository for `AI Javascript Minecraft`, also known as **Voxel World** (though nobody calls it that).
AI JS Minecraft is a primarily AI-generated clone of Minecraft that runs completely in your browser!

The game is relatively well-optimized and includes version compatibility checks since Version 1.9.2. This GitHub repo contains commits for older versions, as well as commits and releases for the officially supported versions!

## Server Startup Flags

| Flag           | Description                                        |
|----------------|----------------------------------------------------|
| --novercheck   | Disables the client version check                  |
| --port:\<port> | Allows setting a custom port to bind the server on |
